# Wagerly

**Stake your success.**

Wagerly is a proposed goal-planning and accountability product. It aims to help
people turn goals into actionable plans, collaborate with an accountability
partner, and track verified progress. Virtual stakes and consequences do not
require financial transactions.

## Proposed stack

JavaScript is the intended language. React, Node.js, Supabase, and Gemini are
proposed technologies, not finalized choices. See
[the architecture overview](./docs/architecture.md).

## Setup

Prerequisites: Git and optionally Visual Studio Code.

```sh
git clone https://github.com/eshadesigns/Wagerly.git
cd Wagerly
code .
```

There are no dependencies to install, application command to run, or tests
configured yet.
