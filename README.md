# Wagerly

An AI-powered goal planning and social accountability application.

## Overview

Wagerly helps users turn larger goals into manageable tasks while staying accountable through friends or accountability partners. Users can create goals, set deadlines, receive AI-generated plans, track progress, and create accountability pacts with virtual stakes or custom consequences.

## Technologies

* JavaScript
* React
* Node.js
* Supabase
* Gemini API

## Features

* User registration and login
* Create goals with deadlines
* AI-generated goal plans
* Edit and complete tasks
* Accountability partners and pacts
* Progress tracking dashboard
* View completed and unsuccessful goals

## Setup

### Prerequisites

* Node.js
* npm
* A Supabase project
* A Gemini API key

### Installation

```bash
git clone <repository-url>
cd goalsync
npm install
```

### Environment Variables

Create a `.env` file and add the required Supabase and Gemini API credentials.

### Run the Application

```bash
npm run dev
```
